
# ESP32_CAM_ATTENDANCE
The ESP32-CAM Attendance System uses a camera to capture student faces and OpenCV for real-time face detection and recognition. Recognized students are automatically marked present, and attendance details are stored and displayed on a webpage, enabling easy monitoring, record management, and accurate attendance tracking.
